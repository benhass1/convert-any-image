# Editorial and structured-data sources

- Camera & Imaging Products Association, [CIPA Standards](https://www.cipa.jp/e/std/std-sec.html). The directory lists current Exif standards, including Exif Version 3.1 published in January 2026 and Exif metadata for XMP published in June 2026.
- Library of Congress, [Exchangeable Image File Format (Exif) Family](https://www.loc.gov/preservation/digital/formats/fdd/fdd000618.shtml). The format description notes that Exif metadata can include technical camera details, date and time information, geographic data and other embedded tags.
- Google Search Central, [Article structured data](https://developers.google.com/search/docs/appearance/structured-data/article). The guidance describes useful BlogPosting properties, including author, datePublished, dateModified and a relevant representative image.
- Schema.org, [Organization](https://schema.org/Organization). The type describes organization identity properties such as name, URL, logo and sameAs.
